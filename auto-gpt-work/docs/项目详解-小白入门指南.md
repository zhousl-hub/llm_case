# AutoGPT 项目详解 - 小白入门指南

## 一、项目概述

这是一个基于 LangChain 框架实现的 **AI 智能体(Agent)** 项目。它的核心思想是让 AI 能够像人类一样思考并使用各种工具来完成任务。

### 什么是智能体(Agent)？

想象一下：你让一个助手帮你完成任务，比如"帮我分析这份Excel销售数据并写一份报告发送给老板"。

传统的 AI 只能回答问题，但智能体可以：
1. **思考**：分析任务需要什么步骤
2. **使用工具**：自动调用 Excel 分析工具、文档生成工具、邮件发送工具
3. **迭代执行**：一步步完成整个任务链

这就是智能体的核心能力！

### 3.2 智能体核心：Agent/ReAct.py

这是整个项目最核心的部分，实现了 **ReAct 模式**。

#### 什么是 ReAct？

ReAct = **Reasoning（推理）+ Acting（行动）**

工作流程：
```
用户任务: "帮我分析这份Excel文件的总销售额"

Step 1:
思考(Thought): 需要先看看Excel文件的结构
行动(Action): 使用 InspectExcel 工具查看文件
观察(Observation): 文件包含"日期"、"产品"、"销售额"列

Step 2:
思考: 现在知道了结构，需要用Python计算总销售额
行动: 使用 AnalyseExcel 工具执行Python代码
观察: 总销售额 = 150000元

Step 3:
思考: 已经得到答案，可以结束
行动: 使用 FINISH 工具返回结果
```

#### 核心代码解读：

##### `__step()` - 执行一步思考
```python
def __step(self, task, short_term_memory, chat_history, verbose):
    # 1. 构建输入（包含任务和历史思考记录）
    inputs = {
        "input": task,
        "agent_scratchpad": short_term_memory,  # 思考记录
        "chat_history": chat_history.messages,
    }

    # 2. 让LLM思考并输出行动决策
    response = self.main_chain.invoke(inputs)

    # 3. 解析LLM输出的JSON格式的行动指令
    action = self.robust_parser.parse(response)

    return action, response
```

##### `__exec_action()` - 执行工具
```python
def __exec_action(self, action: Action):
    # 1. 根据名字查找工具
    tool = self.__find_tool(action.name)

    # 2. 执行工具并返回结果
    observation = tool.run(action.args)

    return observation
```

##### `run()` - 主执行循环
```python
def run(self, task: str, chat_history, verbose):
    short_term_memory = []  # 短时记忆（思考过程）
    thought_step_count = 0  # 思考步数计数

    # 循环思考-行动直到完成
    while thought_step_count < self.max_thought_steps:
        # 1. 思考并决策
        action, response = self.__step(...)

        # 2. 如果决定结束，返回结果
        if action.name == "FINISH":
            reply = self.__exec_action(action)
            break

        # 3. 执行工具
        observation = self.__exec_action(action)

        # 4. 记录思考过程
        short_term_memory.append(...)

        thought_step_count += 1

    return reply
```

### 3.3 模型工厂：Models/Factory.py

负责创建语言模型，支持多种模型：

```python
class ChatModelFactory:
    @classmethod
    def get_model(cls, model_name: str):
        if "gpt" in model_name:
            # OpenAI GPT系列
            return ChatOpenAI(model=model_name, ...)
        elif model_name == "glm-5":
            # 智谱AI的GLM-5模型（通过阿里云API）
            return ChatOpenAI(
                model="glm-5",
                openai_api_key=os.getenv("SILICONFLOW_API_KEY"),
                openai_api_base="https://coding.dashscope.aliyuncs.com/v1",
            )
```

**为什么叫"工厂"？**

工厂模式：就像工厂生产产品一样，根据你的需求（model_name）"生产"出对应的模型对象。你不需要关心具体怎么创建，只需要调用 `get_model("glm-5")` 就能得到模型。

### 3.5 文档问答工具详解：Tools/FileQATool.py

这是一个基于 **RAG（检索增强生成）** 的工具。

#### 什么是 RAG？

RAG = Retrieval（检索）+ Augmented（增强）+ Generation（生成）

工作原理：
```
用户问题: "这个PDF中销售额达标标准是多少？"
    │
    ▼
┌─────────────────────┐
│  1. 文档切片         │  把PDF切分成小块
│  （Chunking）        │
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  2. 向量化          │  把文本转换成数字向量
│  （Embedding）       │
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  3. 向量检索        │  找到与问题最相关的文本块
│  （Retrieval）       │
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  4. 生成答案        │  用检索到的内容回答问题
│  （Generation）      │
└─────────────────────┘
```

#### 核心代码：

```python
def ask_docment(filename: str, query: str):
    # 1. 加载文档
    raw_docs = load_docs(filename)

    # 2. 切分文档
    text_splitter = RecursiveCharacterTextSplitter(
        chunk_size=200,      # 每块200字符
        chunk_overlap=100,   # 相邻块重叠100字符
    )
    documents = text_splitter.split_documents(raw_docs)

    # 3. 创建向量数据库
    db = Chroma.from_documents(documents, EmbeddingModelFactory.get_default_model())

    # 4. 创建问答链
    qa_chain = RetrievalQA.from_chain_type(
        llm=ChatModelFactory.get_default_model(),
        retriever=db.as_retriever()  # 检索器
    )

    # 5. 执行问答
    response = qa_chain.run(query)

    return response
```

class ExcelAnalyser:
    def analyse(self, query, filename):
        # 1. 获取Excel结构预览
        inspections = get_first_n_rows(filename, 3)

        # 2. AI生成代码
        chain = self.prompt | self.llm | StrOutputParser()
        response = chain.invoke({
            "query": query,
            "filename": filename,
            "inspections": inspections
        })

        # 3. 提取Python代码块
        code = code_parser.parse(response)

        # 4. 执行代码
        result = PythonREPL().run(code)

        return result

这个项目展示了一个完整的 AI Agent 实现：

1. **main.py** 启动智能体
2. **ReActAgent** 是核心引擎，实现思考-行动循环
